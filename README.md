# ariv.se

Personal website for Ari Vaniderstine.

## Features

- Responsive design for all device sizes
- Modern, minimalist aesthetic with Ari's signature yellow color
- Proper CV page with downloadable PDF option
- Improved social media links with hover animations
- SEO optimized with proper meta tags
- Accessibility improvements

## Technologies

- HTML5
- CSS3 (compiled from SCSS)
- JavaScript (vanilla)
- Font Awesome icons

## Development

To compile the SCSS to CSS:

```bash
sass style.scss style.css
```

## Deployment

This site is deployed on GitHub Pages from the gh-pages branch.
